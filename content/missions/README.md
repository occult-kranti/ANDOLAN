# Campaign source

The executable campaign data is defined once in `packages/content/src/index.ts` as `CAMPAIGN`. It contains six chapters, 22 ordered stages and seven three-option choices. The host interprets a fixed set of declarative triggers; arbitrary script fields are not supported.

The handoff’s original Last Delivery JSON was a draft schema and is preserved with the source handoff, not loaded as executable content. This preview adapts selected beats into a shorter complete arc; see `docs/GAME_DESIGN.md` and `docs/ROADMAP.md` for production distinctions.
