# Fictional evidence archive

`EVIDENCE` in `packages/content/src/index.ts` is the single authored document registry. Every item includes title, source, body and qualification. These records describe invented people and institutions in Devnagar. They are game content, not factual allegations about real people.

Documents are acquired by the authoritative mission. Qualifications remain adjacent to claims. The innocent name match, unsupported early draft and correction remain in the archive so the player can inspect how the crew’s conclusions changed.
