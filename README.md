# YUGA studio download mirror

Run `python3 rebuild.py assembled` to reconstruct the two artist studios, playable game, animator book, matched photographs and performance. Each file is checked against the published SHA-256 list. GitHub Actions uses the same reconstruction for the draft release upload. The two packed archives are divided into chunks so each Git object fits the hosting limit.
