# YUGA Hanuman studio and trial archive

Download the ZIP to open Hanuman’s editable Blender files, GLB, artwork, both reels, design notes and verification. It contains 50 payloads and an internal checksum manifest. `SHA256SUMS.txt` verifies the outer archive.

The game source and updated play instructions are on [the Hanuman trial branch](https://github.com/occult-kranti/ANDOLAN/tree/game/yuga-hanuman-trial). This archive corresponds to the verified runtime and art checkpoint [12b56789](https://github.com/occult-kranti/ANDOLAN/commit/12b5678915e688ee99baa8170bb35de30c7affb0).
