## Order of use

Current implementation: meaningful decisions, interface feedback, branch memory and coordination. Next measured milestone: game feel and unaided playtests. Later production: resource balance, repeatable contracts and deeper story structure. Reading a book is not itself a shipped mechanic; every adopted lesson needs a design hypothesis and a test in the actual game.
