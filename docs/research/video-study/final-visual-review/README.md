That inconsistency is a **fixture-source limitation**, not an established gameplay defect: the ordinary entry/return images show an appropriately located Sun-spawn marker. Root is correcting the capture fixture to refresh read-only spatial presentation before the successor image. No core/health/winner/reward fabrication is inferred from that stale map.

The result is more useful than a generated screen board as implementation evidence: it shows actual recorded values, a real native chart and a genuine restart. It remains visibly below the requested commercial hero-game artistic target. Large unvaried wall/ground surfaces, broad empty plaza space, simple troop silhouettes and restrained environment/material detail read as a working stylized practice world. The title shares the indigo/ivory/gold hierarchy and blue/gold Rama identity with the concept, but does not reproduce its illustrated anatomy, fine surface detail, layered city density, atmospheric depth or dramatic composition. These are production-art gaps, not claims that the functional checkpoint fails to run.

The [concept board's own notes](../../../concepts/studio-2026-11-15/README.md) reject invented bindings, invulnerability, repel/slow and rain-of-arrows mechanics. Those errors are not runtime requirements. The board is composition inspiration only; this review makes no Overwatch/Deadlock quality-parity, completed roster, online-match, hardware-FPS or finished-map claim.
