# YUGA target board — video-informed direction

Generated on 16 November 2026 from the existing original YUGA world capture,
the observed video patterns and current native service/control contracts.

`yuga-target-board.png` is an **AI art-direction concept, not a runtime capture**.
The richer district, materials, hero treatment and illustrated result staging
are aspirational. Actual implementation and source-bound captures are indexed
in `docs/research/video-study/README.md`.

Accepted as direction: quiet indigo/gold surfaces; the existing Rama identity;
core/elapsed HUD; original four-service field shop; preparation/release/recovery
explanation; original local core result. Verified controls remain LMB/Q/E/C/X,
F4 shop, 300 maximum health and 12 arrows; service prices are original tuning.

Rejected as specifications: the illustrated minimap geometry and traces, dense
environmental art, decorative locks, any distorted glyphs or generated effect
timing. Dawn Volley launches three paced projectiles; the picture cannot
establish their actual timing, collision, damage, animation or performance.
The result trace is illustrative; runtime uses actual recorded core samples.

No reference-game portraits, maps, UI textures or proprietary assets are
bundled. This board was not imported into the game as replacement art.
