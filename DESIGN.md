# Visual direction

The play surface is Experience mode. A stylized monsoon city at blue hour: turmeric signage, terracotta plaster, petrol-teal shutters, warm shop lighting and wet dark streets. The camera stays near the character; the architecture surrounds the player.

The interface uses a restrained printed-cinema identity: warm ivory type, deep ink panels, muted vermilion accents and thin rules. Large condensed display title, practical sans serif controls. Mission cards and dialogue appear only when needed; the game canvas stays dominant. No dashboard grids, statistics wallpaper or decorative pills.

The title screen presents Story, Private Crew and a clearly described online development sandbox. HUD anchors mission top-left, room status top-right, navigational map bottom-left and interaction bottom-center. Keyboard focus is visible, dialog controls use native HTML, text is resizable, touch controls are available and reduced camera motion is honored.

All environment meshes and textures are created procedurally for ANDOLAN. Evidence documents use legible paper layouts and speaker-labeled captions. Sound starts only after an explicit play action and can be muted at any time.
