# Asset intake and export contract

Current runtime assets are generated by original code in `apps/client/src/world/index.ts`; no asset downloads or legacy game data are needed. Concept images live in `docs/concepts` and are excluded from client payloads.

Before introducing a model or audio recording, add a manifest entry with ID, creator, source URL or original-author statement, license, attribution, modifications, file hash, byte size and intended scene. Code licensing does not cover a repository's unrelated music or models.

Future Blender exports: metre-scale glTF/GLB, Y-up, applied transforms, stable node names, simplified collision separate from visual meshes, bounded materials and texture dimensions, and visible landmark silhouettes at low quality. Validate, measure compressed size/draw calls/frame times in the representative district, then replace one asset family at a time. glTF tooling and imported art are production backlog; this directory does not claim an unexecuted pipeline is installed.
