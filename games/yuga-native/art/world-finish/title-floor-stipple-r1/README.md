# Title-floor stipple: narrow diagnostic

Status: diagnostic pending, not a production art fix. No runtime source, texture, geometry, camera, light or renderer setting changed.

Evidence narrows the alternatives. The four actual GLB slab materials share the same512² Pale_limestone normal at0.55 and GREEN roughness map. Embedded/extracted image bytes match. Both compiled GST2 textures contain9 additional mip levels (10 total), independently read using public35e80 `CompressedTexture2D` header layout; missing mipmaps is excluded. The shader uses linear mipmap filtering without an anisotropic sampler hint. Thus increasing project anisotropy alone does not establish a sampling fix. Roughness G spans0.722–0.855. Authored normal detail includes high spatial frequencies; final GPU derivative/TBN behaviour remains unmeasured.

Source GLB bounds show slab topsY0 and foundation top−0.002000004: these surfaces are not exactly coplanar. The inlay intersects the floor, but is local toX±1.306m; it cannot explain uniform stipple throughout all slabs by itself. This is a source geometry audit, not a complete runtime overlap/depth study. `source-audit.json` retains exact bounds/UV/material/header metadata.

The [retained shadow-off original](../../../docs/evidence/rama-quality/lookdev/floor-artifact/probe-r1/title-day-shadows_off.png) still visibly has fine dotted joints. [Ground-casting-off](../../../docs/evidence/rama-quality/lookdev/floor-artifact/probe-r1/title-day-ground_cast_off.png) does too, although the earlier broad radial acne was removed. These prior frames use the same GLB/maps; their lighting/masonry generation differs from today's current frame. They establish that residual stipple can exist without directional shadow PCF, not that every current pixel has the same cause. Do not repeat the earlier bias/ground-shadow isolation or remove accepted hero/building shadows.

Next single-variable probe: `diagnostic-only.patch` changes only the `normal_depth` uniform binding from the original imported value to0 for exact `Courtyard_stone_0/1/2/3`. Original normal textures stay bound; normal-enabled flags, all roughness/scalar channels, base colour, mineral wash, shader code, inlay/mortar, exposure, sky, SSAO, shadow receiving and geometry remain. All other material depths retain their original values. This isolates normal perturbation without altering texture import or broad lighting. It is deliberately a diagnostic reduction, not a proposed quality downgrade.

Use unchanged634 snapshot and original two-shotcbd72 scene-anchors helper for matched title/training, with identical camera/pose/phase, same engine and copied warm seeds. Inspect slab interiors separately from joints/inlay. If only interior grain clears, record mixed causes; if stipple persists, normal perturbation was not necessary in that view. A positive result implicates normal-dependent shading but does not by itself distinguish mip/anisotropic sampling, TBN or normal-dependent SSAO/shadow response. Only then consider a sampler-only anisotropic control retaining normal strength. No TAA control is first choice: it could blur geometry, normals and SSAO together and would not isolate the cause. A later single TAA control may assess remaining subpixel joint sampling after this split, with ghosting/hero-detail costs reviewed separately.
