# Sources and rights

The anatomical surface derives from the existing repository's MakeHuman CC0 data under `games/yuga/art/sources/makehuman`. Its pinned source manifest and license documents are retained there. The skeleton and original project animation curves are imported from `games/yuga-native/art/production/reconstruction-rama.blend`, whose provenance documents distinguish the reconstructed file from the missing original modeling history.

The new garment geometry, sculpted hair surfaces, jewelry, bow, quiver and deterministic PBR textures are original work for YUGA, dedicated under CC0-1.0. The included source generator makes those surfaces editable and reproducible; it does not reconstruct hidden source geometry from the generated concept image. The canonical reference image is used as visual direction and is not baked onto the model.

No Deadlock, Overwatch, Dota or other commercial-game client asset, animation or texture is part of this candidate.
