# Sangam art direction

`art-direction.png` is a generated **concept reference, not gameplay**. It was
generated in this task with the imagegen skill and built-in image tool, then
copied into the project. SHA-256:
`d4056c77718b8321840154d9a153f22220aa45376a364bb821548ab6878297a9`.
It is excluded from the runtime package by the existing authoring boundary.

The brief asks for an original fictional South Asian civic quarter: sandstone
colonnades, indigo archive facades, carved brackets/chajja, recessed lattice,
aged brass, hipped galleries and chhatri silhouettes, warm stone paving,
readable aiming space, useful cover and sheltered side routes. Rama's indigo
drape/ivory dhoti/bow provide scale. It requests no copied commercial assets,
modern glass towers, neon, magical clutter or invented gameplay HUD.

The concept's continuous open interiors, trees, flowers, dense small carvings,
organic cloth and fully realistic lighting are aspirational. A generated image
does not supply their editable geometry, collision, rig, materials or achieved
performance. The actual Blender source and imported Godot district are judged
independently; do not advertise this image as an implemented screen.

The map author uses it for material/silhouette/scale hierarchy. The gameplay
contract takes precedence: eight retained ground blocker footprints, useful
ground routes, four honest solid cover volumes, and native-only overhead
connectors. No false accessible interior is added inside a solid blocker.
