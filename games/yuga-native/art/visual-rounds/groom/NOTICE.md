# R3 groom provenance

The new fitted scalp shell, crown/temple/nape guide geometry, generator,
measurements and validation code are original work for YUGA, dedicated under
CC0-1.0 consistently with the retained original hero art. No commercial model,
texture, animation, generated concept mesh or scraped strand asset is reused.

The inputs retain the project's CC0 MakeHuman anatomical data and original
authored hero geometry, hair textures, rig/animation and facial-form stages.
Their source notices remain applicable: `art/hero-rama/NOTICE.md`,
`art/hero-rama-face/NOTICE.md` and
`art/visual-rounds/face/NOTICE.md`. This stage does not supersede those notices.

`art/hero-rama-lod/glb_lod.py` supplies the existing project GLB reader. Python,
NumPy and SciPy are execution dependencies, not vendored assets. The separate
Khronos validator and role07 frame probe keep their own existing notices.

The original eyebrow/topknot records, all materials/images and every nonhair
binary byte remain exact. Source hashes and inspected baseline images are in
`source-manifest.json`; exact generated output identities and limitations are in
`docs/evidence/visual-rounds/round3/role08/`.
