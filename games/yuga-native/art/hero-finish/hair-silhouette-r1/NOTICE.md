# Original authored hair silhouette experiment

The new swept lock paths, tapered profiles and three LOD meshes in this directory are original YUGA work, dedicated under CC0 1.0. They retain the existing project hair material and texture, original eyebrows/topknot, MakeHuman-derived CC0 anatomy, rig and other source assets without relicensing or replacing them. See `art/hero-rama/NOTICE.md`, `art/visual-rounds/groom/NOTICE.md`, and the accepted `art/hero-finish/s4-diadem-smooth/NOTICE.md` for inherited notices.

The existing `games/yuga/art/references/rama-hanuman-sita.png` was inspected for visual direction only; no pixels, mesh, texture or image-derived geometry from that reference is embedded. No external mesh, hair-card library or commercial asset was added.

This is an inactive review-only candidate. It is not a packaged model or approval of whole-character art, current renderer performance, or continuous gameplay contact behavior. Historical rejected attempts remain as explicit counterexamples. The exact accepted smooth-crown R2 parent is mandatory for the current candidate; old-band checks are diagnostic only.
