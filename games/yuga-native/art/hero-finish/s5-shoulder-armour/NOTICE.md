# Original S5 layered shoulder armour

The curved cap, overlapping plates, rolled edges and lotus relief in this
directory were authored for YUGA with the retained deterministic Python source.
The existing repository's Rama identity reference guides the design. No
commercial model, extracted game geometry, external texture, downloaded asset
or new image-generation output was used to construct these meshes.

The existing original Rama mesh supplies only measured anatomy, clearance
surfaces and its documented rig coordinate frame. Its mesh arrays are not
copied into the new armour or modified. The optional diagnostic helper borrows
existing live material resources; their original notices remain applicable.
The source uses the repository's existing GLB reader, NumPy/SciPy and retained
triangle probe. Their existing licenses/notices are unchanged. This notice
does not grant new rights in the retained reference or upstream dependencies.

All three GLBs remain inactive review candidates with documented action
intersections. They are not additions to the accepted runtime asset manifest.
