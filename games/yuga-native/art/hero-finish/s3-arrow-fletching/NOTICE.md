# Original S3 arrow fletching candidate

The profile, triangle geometry and authoring script in this directory were
created for YUGA. They use no third-party model, photograph, extracted game
asset or generated image. The editable radial/axis profile is in
`build_fletching.py`; `candidate-mesh.json` is its deterministic output.

The optional native helper borrows an existing hero instance's finished ivory
material. It creates no textures or materials and does not change their
properties. Existing Rama GLB, rig, animation and material notices remain
applicable to those unchanged resources. This notice grants no additional
rights in those separately retained sources.

This is a review candidate, not an accepted or packaged runtime addition.
No canonical source GLB, player, socket, bone or arrow controller is replaced.
