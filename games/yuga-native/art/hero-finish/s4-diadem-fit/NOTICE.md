# Original S4 diadem rail refit candidate

The fit procedure and editable source in this directory were created for YUGA.
They modify only the project's original lower diadem rail from
`art/hero-rama/build_hero.py` and its original `Sculpt.ring` authoring routine in
`games/yuga/art/pipeline/geometry.py`. No commercial model, extracted game asset,
external photograph or generated image is used.

The candidate retains the existing Rama GLB's separately documented anatomy,
rig, animations, groom, face forms, materials and textures. Their notices and
source obligations remain applicable. This notice does not grant new rights in
those retained inputs. Existing NumPy/SciPy, GLB reader and narrow-phase sources
retain their existing notices.

These copied GLBs are inactive review candidates, not accepted runtime assets.
