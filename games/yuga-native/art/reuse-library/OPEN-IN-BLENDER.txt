YUGA world elements • Blender 4.3.2

Extract the entire folder. Open yuga-world-elements.blend to see the gallery.
To use pieces in another file, choose File > Append, select the .blend, open
Collection, and choose a named asset. Use File > Link for shared masters.

For drag and drop, open Edit > Preferences > File Paths > Asset Libraries
and add this folder. Choose it in the Asset Browser. Keep blender_assets.cats.txt
beside the .blend to see Architecture, Nature, Foundations and Symbols.

The 15 architecture and nature pieces are existing YUGA works. The four
foundations are stock editable forms at dimensions used by the FireRed remake
renderer. The 24 signs use the bundled DejaVu symbol font. The original font
license and credits are in symbols/DejaVu-LICENSE.txt.

The library packs its textures. World presets keep their normalized source
dimensions. The display_scale_xyz values in catalog.json record the gallery
proportions before preview normalization.

Sources, rebuilding and the separate Rust fallback study:
