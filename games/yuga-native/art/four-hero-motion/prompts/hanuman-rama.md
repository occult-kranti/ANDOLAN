# Hanuman and Rama art direction and generation record

Each hero has a 1,536 × 1,024 sculpt reference and a 2,172 × 724 action triptych. The latter divides evenly into three 724 × 724 frames. The outputs are generated 2D concept art for modeling and timing. Independent Blender playblasts and game footage are the evidence for mesh deformation and runtime behavior.

The existing hero images were inspected in color before being supplied to ImageGen. For the second pass, each completed sculpt sheet was the sole image reference for that hero’s new action strip. The sheets preserve the generator’s PNG files. The triptychs use lossless WebP for distribution. Neutral staging and a consistent screen-right action axis support direct comparison. [Gameplay kit definitions](../../../../yuga/shared/heroes.ts)

## Hanuman

The storyboard follows the classic Sangam R ability. Its action label is **Mountain Pulse**, and the underlying movement mechanic is **Mountain Descent**. The hero braces for 0.70 seconds, travels for 0.45 seconds and triggers the area effect on landing. The enhanced Confluence kit uses a separate remote ground pulse while the caster stays in place. The reel uses “Mountain Descent” to identify the jumping performance. The quoted historical ImageGen prompt below retains the original ability label. [Hanuman animation script](../scripts/hanuman.md) · [Classic kit](../../../../yuga/shared/heroes.ts)

The back view gives the clearest read on the tail root and brush. The tail nearly overlaps the body in the neutral profile, so use the rear and airborne views when laying out a spline. The chest stone, lotus apron and bronze gada carry across both images.
