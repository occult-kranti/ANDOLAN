# Hanuman dusk court sources

The editable reference-matching set is generated by [court.py](../../../tools/hanuman-match/court.py). It places actual 3D architecture, wet setts, oil lamps, bells and a finite haze volume around the assigned camera. It uses the generated keyframe to guide composition and material scale.

The three downloaded JPGs total 2,457,643 bytes. Each matched the official file API length and MD5. The builder checks their SHA-256 values recorded in the [source manifest](source-manifest.json) before loading and packing them. The source GLB SHA-256 and selected triangle counts are also checked at build time. Its selected triangles are read directly and reassembled as editable Blender meshes with the donor UVs. The studio materials and Blender-computed geometric normals may differ from the original exported game materials.

The perspective camera must be set before `apply(scene, profile)` and the scene must be active. The set keeps ground at Z=0 around the hero. It constructs the near pillar and hanging bells along the actual frame edges with horizontal right and depth axes derived from the camera, then creates separate background layers. Set `near_column_depth_m`, `near_column_screen_x`, `haze_density` or `background_fill_strength` in `profile["court"]` to tune placement and light. Seeded placement and batched meshes produce 1,094 wet setts. The builder reports object, light and triangle counts. In a Blender 4.3.2 test it produced 53 court objects, 12 lights and 104,861 triangle-equivalents. There are no external Blender-library links.

The first integrated preview showed a bright, narrow passage with oversized lamps. The second pass pulled the galleries back, darkened and enlarged the setts and reduced lamp scale. Fixed-crop floor medians moved from RGB `(171, 158, 144)` to `(85, 84, 82)` against the reference `(72, 62, 59)`. The third pass added exposed relief, lower distant rooflines and soft blue fills that point away from the hero to separate the tower faces even in dusk. The fourth moved the lotus pillar another 3% of frame width toward the right to give the tail a cleaner contour, and put charcoal weathering and reflective wet patches at different spatial scales across the foreground. The crop values are approximate visual diagnostics because the integrated hero lighting was revised as well.

The module is a presentation set. It does not define navigation, combat collision, gameplay lights, or a new exported map. The lock on the original source files preserves the verified Hanuman trial.
