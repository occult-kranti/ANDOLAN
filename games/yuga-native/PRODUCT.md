# YUGA native

This context belongs to the Godot desktop game in `games/yuga-native`. The root ANDOLAN product documents describe a separate browser game. Source baseline: `1b2e6f5202490036a6195581f2901a2075750b56`, the corrective startup regression following the accepted one-building frontage checkpoint `0964564d1ba283a5ac0aee8eab0a6cccd8f443f3`; later UI work needs its own verification. Neither checkpoint changes the public preview’s source identity.

YUGA is an original mythology-inspired third-person action game. The playable build offers Rama, his bow and four abilities in **offline practice**. Confluence contains local army battles, three lanes, relays and core outcomes; Bow training provides courtyard targets and resettable practice. “Watch duel” opens a scripted presentation, not a multiplayer match.

The immediate player journey is to choose a practice, understand what it offers, enter it, learn the current bindings, act, recover from defeat or reset, and return to the menu. Help, Rama’s abilities and settings support that journey. Loading must describe the actual phase and provide truthful recovery; resource progress is not total scene readiness.

Desktop mouse and keyboard are the current target. Preserve native focus, input remapping, readable text scaling and saved preferences. The supported base window is 960 × 540; inspect 100%, 150% and 200% UI scale without hiding essential actions. Mobile implementation is deferred.

The [published desktop preview](https://github.com/occult-kranti/ANDOLAN/releases/tag/yuga-desktop-finish-2026-10-18) is source `96d5b9cd3114b9732f7dc80433b1ca0a1d4a9b12`. Its Linux execution and download evidence do not qualify later source changes; Windows remains unexecuted. The production plan is 6v6 with fourteen heroes, three lanes and an 18-minute match; the fourteen-invocation study through one avatar does not deliver that roster. Native online matches, a finished fourteen-hero roster, physical-GPU performance and the Deadlock-level art target remain future work. Do not advertise them as available.
