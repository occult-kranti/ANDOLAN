# Sangam Crossing tactical map

The new tactical layout, map adapter, floor/site marks, route data, collision
assembly, partition/cover details and tests are original YUGA project work.
This is a fictional South Asian civic arena, not archaeological reconstruction.

`assets/world/sangam-district.glb` and its companion spec are reused without
modification. Their geometry was authored for YUGA. The existing sandstone,
limestone, indigo and brass texture inputs retain their CC0 dedication in
`ASSET-NOTICE.md` and original provenance in `NOTICE/HERO-SIX-ROUNDS.md`.
The original `shaders/sangam_masonry.gdshader` is reused unchanged with private
material instances. Exact source hashes are in `assets/tactical/map.json`.

Riot, Valve, Blizzard and user-supplied MP4s inform design research only. No
commercial map, character, weapon model, interface artwork, audio, extracted
resource or proprietary implementation is included by this map. Reference
articles grant no asset license. Existing Godot and other asset notices remain
in force. Research frames and articles are not runtime assets.

The R2 visual correction also reuses immutable original YUGA
`assets/world/architecture.glb`, `assets/world/nature.glb`, and the shared
world-paving shader/include. Their existing ASSET-NOTICE.md terms remain.
New stall/awning assemblies, planted-edge composition, shared procedural leaf
clusters, skyline arrangement and lighting are original project work. All new
source associations are pinned in the tactical map JSON. No source texture
pixels, imported model bytes or earlier world adapters were modified.
