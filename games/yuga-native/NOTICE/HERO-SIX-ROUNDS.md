# Rama hero continuation — YUGA-HERO-6R

The new ability timing meter, two-tone projectile-lane warning shader,
receipt-driven training observer, and tactical guide text are original project
work. Existing Rama meshes, rig, textures, sounds, fonts, world art and Godot
runtime retain their existing per-asset notices and provenance.

The Sangam civic district is original project geometry authored with Blender.
Its eight building shells, four civic cover monuments, two avenue galleries,
eight covered eaves and perimeter galleries are exported in
`assets/world/sangam-district.glb`; the companion JSON pins the editable source
and twelve reused original YUGA courtyard texture inputs. Those sandstone,
limestone, indigo and brass maps retain their existing CC0 dedication in
`ASSET-NOTICE.md`. No new external texture or commercial-game mesh is included.
The district adapter and quiet sandstone paving shaders are original project
work. The generated art-direction image is excluded from runtime packages and
is explicitly labelled concept art, not gameplay evidence.

The user-supplied `gameplay.mp4` and `all ults.mp4` were reviewed locally as
design references. Video frames/contact sheets stay in the research record and
are excluded from native packages. No Valve character, map, texture, audio,
interface artwork, extracted resource or proprietary game implementation is
included by this continuation.

Public open-source tools and inspected repositories are cited with access,
revision and licensing scope in `docs/research/hero-six-rounds/reference/`.
Source research does not imply a new runtime dependency or permission to
redistribute an inspected game's assets. Existing Godot, Blender, glTF and
FFmpeg tooling is used for the native production/validation workflow.
