## Confluence: a duel of timing

An original 24-second Rama-versus-Ravana Sentinel combat film, built in the native YUGA project. It demonstrates a blocked solar arrow, a telegraphed spectral wave, an evade and a countershot. The actors use two rig-specific animation libraries with nine clips each, original costume work, timeline-driven effects and an original synthesized soundtrack.

### Watch or run

- **Watch:** download `yuga-confluence-duel.mp4` (720p, 24 fps, stereo sound).
- **Linux:** extract the entire `yuga-native-linux-x86_64.zip`, then run `./launch.sh`.
- **Windows:** extract the entire `yuga-native-windows-x86_64.zip`, then run `launch.bat`. Windows is packaged and archive-validated; it has not been executed on Windows here.
- Choose **Watch Confluence Duel** from the title. Playback supports pause, seeking, replay, captions, static camera, reduced flashes and the saved game volume.
- The same package includes **Explore Confluence** and the existing courtyard training mode. No editor installation is required.

### Verification and scope

The release includes source-hash reports, package manifests and SHA-256 checksums. The video consists of 576 sequential engine-rendered frames. Animation checks cover finite skeleton transforms, planted-foot geometry, action boundaries and deterministic backward seeking. A guard-reset speed defect was corrected before the final render. Original audio timing and encoded waveform correspondence are checked numerically; listening quality has not been independently reviewed.

This is an animation and presentation prototype. The duel is scripted, not a playable or network-authoritative fight. The complete hero roster, native competitive multiplayer, production animation polish and Deadlock/Overwatch-level visual quality remain open roadmap work. The film retains visible floor aliasing, simple materials and sparse scenery. Software rendering here does not establish gaming-GPU performance.
