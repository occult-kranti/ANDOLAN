# Confluence world in Rust

The Rust drill reads the existing native Confluence map and uses Parry 2D for horizontal movement, walls and ability clearance. The native Godot build remains the comparison for full 3D terrain and traversal. Both the native test binary and browser WebAssembly library compile the same Rust world module. [Rust authority](../../../yuga-rust/src/world.rs) · [Existing native scene builder](../../scripts/confluence_world.gd) · [Canonical game map](../../assets/world/confluence-map.json)

## Imported map and gameplay contract

The byte-identical authoring and runtime map copies have SHA-256 `d39043bfaabd9c3e173f03d68423269b5308b60c6906968315405690f844d77c`. The loader compiles the staged runtime JSON into the Rust binary with `include_str!`. Changing this asset therefore requires rebuilding the WebAssembly. The standalone renderer consumes the matching map copy from its package. The map uses metres with +Y up. The horizontal authority works in X and Z, where team Sun faces +Z. [Authoring map](../../art/world/confluence-map.json) · [Runtime map](../../assets/world/confluence-map.json)

The ground-disc and point-ray paths intentionally have different radii. Cast acceptance also checks its own map bounds and horizontal clearance. A sight line from `[0,126]` to `[0,135]` crosses no wall but leads outside the floor, so sight alone cannot authorize Mountain Pulse. A vault from `[-8,-28]` toward −X with a range of 8.5 m and 0.48 m clearance stops at approximately −10.3075 m after the native 0.025 path-fraction setback. At a map edge the locked plan can reach Z=127.52 m while the actual 0.65 m actor stops around Z=127.35 m. [Godot ability acceptance](../../scripts/hanuman_combat.gd) · [Native wall and bounds rules](../../scripts/lane_army.gd) · [Rust movement and vault helpers](../../../yuga-rust/src/world.rs)

The ground representation lacks height-varying platforms, stairs, overhead occlusion, slope contact, dynamic bodies, flight and grapple. The Godot source constructs all eight decks, then can replace the Sun west lift's coarse solid with detailed wind-court collision. That option defaults on in the native scene. The Rust drill uses the coarse footprint for this landmark. Movement results are repeatable for the tested map/input sequence and locked target. Cross-CPU bit-identical physics and networking have not been qualified. [Detailed body replacement](../../scripts/confluence_world.gd#L416) · [Wind-court builder](../../scripts/traversal_landmarks.gd)

## Five reviewed rounds and next acceptance gate

| Round | Moderator question | Decision and witness |
| --- | --- | --- |
| 1 · Locate | Which assets and boundaries are already present? | Read the staged map, native consumer and art library before selecting a Rust engine. Freeze the two identical map files and the six upstream heads. |
| 2 · Challenge sources | Which symbols fit the current world format, coordinate system and licenses? | Prefer a small geometry crate for live physics; keep reference-only games, conditional editor imports and their art licenses separate in the matrix above. |
| 3 · Build | Can the Rust world read and constrain the real map? | Exercise Parry against the 8 + 8 blockers, all three clear lanes, a fast wall approach, tangent motion, rounded corners, a stuck start, the outer bounds and invalid map data. |
| 4 · Cross-check combat and art | Can a shot plan aim outside the arena? Can a real collider be invisible? | Added separate ground-target acceptance and clearance-aware vault and release queries. Regression cases exercise off-map targeting, near-wall shortening and planned/actual edge landings. Mapped all eight native decks to their landmark visuals. |
| 5 · Verify and hand off | What is the next falsifiable parity claim? | Six Rust world test groups cover the route, motion, targets, ability margins, input validation and spawn/visual mappings. The next parity gate compares actual native deck geometry at the same coordinates before moving from coarse XZ footprints into 3D. |

Rust 1.88 passed all six world tests in the native test binary and compiled the optimized WebAssembly library. The browser renderer adds the 63 placements, then builds all eight deck silhouettes and exposes all 16 visual collider IDs for its browser test. [Scene builder](../../../yuga-rust/web/scene.ts) · [Browser coverage](../../../yuga-rust/tools/test_browser.mjs)

To reproduce from the repository root, install Rust 1.88 and its `wasm32-unknown-unknown` standard library and run the following commands.

```sh
cargo test --locked --manifest-path games/yuga-rust/Cargo.toml --lib world::tests
cargo build --locked --release --manifest-path games/yuga-rust/Cargo.toml --target wasm32-unknown-unknown --lib
```
