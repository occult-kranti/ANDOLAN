# The REA fork network, queried to its terminal page

The public `morluto/rea` forks endpoint returned **116,393 distinct repository IDs on 1,165 pages** in an oldest-first traversal on 25 November 2026. The starting repository metadata reported 116,321 forks. Both figures are retained because the listing changes during collection and upstream counters have their own timing. There were zero duplicate repository IDs in the pages returned. The archive includes names, IDs, default branch, creation time, descriptions, topics and the language GitHub reported. Download it to inspect the whole enumeration. [Compressed TSV](rea/direct-forks.tsv.gz) · [Counts, query and checksum](rea/direct-forks.json) · [Repeatable collector](rea/fork-inventory.py)

GitHub supplied **no primary language for 106,949** of these repositories. Its primary-language field named Rust for just two. We applied a multilingual game-keyword filter to the repository name, topics and description and retained either game matches or a Rust language label. Owner handles were excluded from the keyword scan. This produced thirteen leads and demonstrates how readily metadata misses independent games published elsewhere by the same developer. We inspected all thirteen plus four known game-associated forks, listing a combined 457 branch references and reading their pinned READMEs. Each record includes the actual Git parent and source network. [Pinned inspections](rea/direct-fork-inspections.json) · [Owner and adjacent-game research](REA-GAMES.md)
