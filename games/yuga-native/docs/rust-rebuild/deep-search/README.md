# Confluence in Rust: source research, playable match and handoff

**25 November 2026.** The downloadable game now runs a complete Sun-versus-Moon lane match with Hanuman or Rama. You can play alongside the Sun army locally or join the other team in a private two-player room. Rust owns the armies, damage, projectiles, clock, hero respawns, gold and core outcome. Both heroes use their existing skinned models and authored action performances. The original three-guard Hanuman practice remains in the menu. ### One donor that shipped

The MIT-licensed stereo limiter from the OpenBF *Star Wars Battlefront* engine rebuild now processes the game’s audio in a Rust/AudioWorklet instance. Its upstream source and license ship with YUGA. The test mixed two copies of six existing Hanuman sounds. An input peak of 1.193176 stayed within full scale, and quiet audio remained sample-exact after the two-millisecond delay. The browser uses its own compressor when AudioWorklet support is unavailable. No Battlefront sound recordings are needed. [Source, sample-rate cost and browser measurements](AUDIO-PORT.md)

## Play and reproduce the release

Extract the ZIP and select **Play lane match** for solo play. For two players, run `node serve_rooms.mjs` inside the extracted folder and open `http://127.0.0.1:8787`. The same host can serve a LAN. Node 22.12 or newer is required for hosting. The game archive includes the host, its bundled WebSocket dependency, and the Rust/Wasm worker. Linux Chromium verified 29 original drill checks, 18 checks for local matches and nine for actual two-browser play on the extracted host. The two browsers reproduced movement and accepted casts across opposing seats. Three additional checks captured Hanuman’s rear sweep and Mountain Pulse on the opposing screen, including both the windup and travel poses. Physical GPU performance and wide-area network play are future measurements.
