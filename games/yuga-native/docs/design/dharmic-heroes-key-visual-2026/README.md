The current Rust/PlayCanvas package has Hanuman and Rama as playable heroes in a private hero-only skirmish. Arjuna has a design and an implementation in a separate older browser roster; Krishna has an editable development rig and motion study. Kali is a new proposed visual direction here. None of those three is thereby a playable hero in the current Rust match. Soldier waves remain paused for that match. Native Godot, the earlier browser roster and the current Rust build have different capabilities and must be checked separately.

The concept is a creative interpretation, not a claim of a definitive religious or historical depiction. The Indian traditions represented here are living and diverse; identify specific source works and obtain knowledgeable review for iconography and inscriptions before final production. The current museum gallery supports studies of Hanuman's mountain carry, Rama's repose, Krishna's protective grouping, and lighting/composition; it does not source every proposed feature of this new ensemble. A verified source study for Kali and each proposed Sanskrit inscription remains open.
