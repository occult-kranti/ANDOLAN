# Five-hero art production roadmap

This is a **proposed art track**, not a completed-game schedule or a change to the existing production ledger's status counts. The current competitive direction is private **5v5 hero-only** matches, with minion waves paused. Keep the current Hanuman/Rama skirmish and its [known two-rendered-client effect stall](../vanara-sena-2026/README.md) visible while extending the roster. No stage below is accepted merely because a generated image exists.

## Production rules

- The current PNG is **1672 × 941** and flattened; a 4K layered source, separate portraits, a Blender scene based on this composition, animations and game assets remain to be authored.
- Reuse current YUGA source assets when their provenance and intended skeleton fit the task. Check every outside asset and license individually; visual inspiration from another game does not itself grant a license to its models, textures or code.
- The approved model's topology, UVs, skin weights, materials and clips must survive the exact engine import. Compare actual in-game captures against the same posed/camera reference; do not use an offline film as evidence of runtime quality.
- Treat color as one cue among shape, labels, motion and audio. Check accessibility, visual clutter and the opposite team's view before calling an effect competitive-ready.
- The previous 20 Hz Vanara Sena field remains the source of its gameplay timing and damage. This art packet does not add Krishna, Arjuna or Kali rules, a boss fight, god-mode powers, lane minions or an online deployment.

Suggested execution order: source/approval → five boards → reusable lookdev → Hanuman vertical slice → additional heroes → environment/VFX integration → hardware and multiplayer qualification. Work can be parallel within a stage when owners have separate files; exports and shared package changes are serialized.
