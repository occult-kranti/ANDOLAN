# Open art wave: implementation and review

This archive belongs to the [next fifteen assignments](../../OPEN_ART_WAVE.md).
The current hero and published preview retain their separate identities.

Packets are grouped by output: `mesh/`, `materials/`, `uv/`, `toolchain/`,
`integration/`, `seams/`, `render/`, `deformation/` and `qa/`. A packet's receipt
states whether it is implementation, a numerical check, a source/license check
or actual rendered review. Candidate generation does not authorize promotion.

The moderator's final review and manifest will record completed assignments,
preserved failures, actual image findings, source identities and outstanding
work. During implementation, a missing packet is pending rather than passed.
