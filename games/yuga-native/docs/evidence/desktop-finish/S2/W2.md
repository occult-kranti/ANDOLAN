## Changes

New `scripts/loading_presentation.gd` creates a lightweight native loading/recovery plate using bundled serif/sans fonts, indigo/ivory/gold and a fine gold rule. It gives destination/status a stronger hierarchy than the old oversized wordmark, reserves the resource region, and keeps the action band outside a scrollable body. The outer plate and action band retain their geometry when progress or Retry appears. Short/scaled windows retain visible recovery actions while long explanatory text can scroll.

The view distinguishes **Practice menu**, **Offline lanes** and **Scripted duel**. Percentage copy explicitly covers scene resources, with scene preparation still to follow. Unknown progress/construction never invents a percentage or separate map/hero-ready checkmarks. Busy-state Back reads **Cancel loading**; failure retains **Retry / Back**. W6 owns the requested boot subtitle change from “Confluence” to “Offline practice”, which clarifies that boot enters the practice menu rather than the world.

The helper exposes the controller's existing six Control references and consumes phase/destination/progress for labels only. It does not initiate work, retry/cancel, modify progress values or bar visibility, enable/disable controls, move focus, alter scene readiness/tickets or await frames. W6 serializes `_build()` delegation and keeps signal/focus wiring and all navigation logic.
