## Implemented behavior

Before loading/commit it cancels if a different live scene has replaced that source; restoration and deferred window-focus policy respect the new owner. Ordinary same-scene paused cancellation, duplicate/reentrant attempts, exact phase/progress suppression and late resource cleanup retain their existing contracts. `boot.gd` also checks that it is still the active scene before opening or handling persistent-loader callbacks.

W2's new `loading_presentation.gd` supplies the view. W6 replaced only the controller's construction of that view, preserving all six public controls, button connections, focus wiring, signals and lifecycle state. The boot subtitle is now “Offline practice.” Resource percentages still come from `ResourceLoader`; scene construction remains synchronous. `scene_changed` acknowledges mounting, not shaders, actor readiness or the first rendered world frame.

The new host fixture exercises queued/loading/error replacement, detached/freed callers, disposed overlays, an attached old caller, stale window-focus policy, obsolete boot reentry, same-host paused restoration and successful reuse. Its final negative control fails 16 of 47 checks against S1 sources with no engine diagnostic; the candidate passes all 47. The first two attempts also exposed unsafe fixture access after an intentionally freed node; their original diagnostics remain under `baseline-r1` and `baseline-r2`. Only the fixture guards changed before the clean negative control.
