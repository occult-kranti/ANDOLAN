## Observation and implementation

The retained R7 `candidate-r7/actions/{kodanda,piercing_dawn}-normal.png` originals
show the thin held arrow while the quiver has recognizable ivory feathers.
Those captures predate current motion. Inspection of original
`art/hero-rama/build_hero.py` and current `rama_motion.gd` confirms that the held
arrow consists of a six-sided shaft and four-sided tip with no fletching. The
existing leather grip, gold wires, string and hand/socket ownership already
have original authored detail; this packet does not duplicate or move them.

The new optional `scripts/rama_arrow_fletching.gd` adds three original closed
vanes beneath the existing NockedArrow at identity. It uses one shared ArrayMesh
(60 triangles, 180 vertices), one extra MeshInstance3D per configured arrow and
the existing hero's finished ivory material. It adds no textures, materials,
callbacks, bones or transform/visibility writers. The geometry cache retains
no material. Explicit release or tree exit releases owned geometry; an instance
transferred to another parent is preserved. Nothing calls this helper by
default. The editable source, deterministic data and notice are in
`art/hero-finish/s3-arrow-fletching/`.
