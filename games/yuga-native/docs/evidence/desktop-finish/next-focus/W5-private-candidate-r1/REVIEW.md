# Private focus-recovery candidate — W5

The two private scripts fix backward keyboard recovery when the current control is absent or excluded from the focus order. Canonical runtime files and the exact `f8dec5fa` package remain unchanged. This candidate is not yet integrated or visually qualified.

The initial component witness retained in `initial-failure/` has 5/7 passing predicates. Disposing the guide’s actual effect receiver disables the focused option; Shift+Tab then selects Dawn Volley instead of Back. Explicitly clearing viewport focus reproduces that selection. Controls reaches Done but logs a script error because its conditional expression tries to use the return value of `grab_focus()`, which returns void.

The expanded unchanged fixture in `comparison/cases.gd` passes 19/26 predicates on the retained baseline and logs 10 script errors. It additionally demonstrates freed focus-list entries being dereferenced. The private candidate passes all 26 predicates with exit 0 and a clean engine log in 0.817 seconds. The same fixture and official `f64d4ed1` engine were used for both runs, with CPU4 affinity and LP/OMP/OpenBLAS set to 1; this does not cap the engine worker pool.

The patch adds an explicit first/last selection when the focused control is absent or filtered out, preserves the existing modulo traversal for a valid current control, and skips freed entries. Controls uses ordinary branch statements instead of a void-valued conditional expression. No button-builder refactor, binding change, caller pause/return change, or courtyard repair is included. The courtyard’s similar source formula remains untested and unchanged.

The 26 predicates cover normal forward/backward wrap; missing, disabled, hidden and freed focus peers in both shared components; actual guide effect-receiver disposal; guide Up/Down recovery; unchanged bindings; and exact canonical/private source stability. The disposed-peer cases insert and then free one explicit focus-list child; they are component lifetime adversaries, not a claim that an ordinary user route disposes that child.
