# S1-W6 — boot recovery and package candidate closure

Fixed a reproduced boot lifecycle error: when a live boot caller was detached during loading, the persistent loader correctly cancelled, but the boot callback still called `grab_focus()` on a detached button. Godot logged `!is_inside_tree()` from `boot.gd`. Detached callbacks now leave abandoned boot UI alone. Hidden or disabled boot recovery does not steal focus from the replacement host, and the loader rejects focus restoration to an explicitly disabled processing owner, a disabled button or a control with no focus mode.

The final checks pass **334/334**: new boot/recovery cases **29**, existing seeded transition stress **35**, existing boot fixture **29**, updated graphics package adversaries **133**, and PCK security **108**. They use copied scripts, bundled fonts and tiny scenes with real threaded ResourceLoader calls. No W6 editor import, 3D render, export or startup-performance measurement ran. [Execution receipt](W6/execution.json) records exact sources, commands, raw logs and outcomes.

The same final 29-case test against the exact checkpoint boot and loader fails **9 cases**, retains the detached-focus engine errors, and exits 1. It covers queued/loading/error detachment, cancellation ownership, late failure isolation, live-object reattachment, hidden/disabled callers, disabled openers, ordinary Retry/Quit focus, successful real small-scene completion and one persistent loader. The original reproduction and historical source copies are retained under `W6/initial-probe`.

Two intermediate failures are preserved. The first test version sampled the caller after the loader temporarily disabled it; that expectation was corrected to boot's original ALWAYS processing mode. The first general `can_process()` guard then rejected six legitimate paused-caller restoration cases in the existing stress test. The final guard distinguishes an explicitly disabled processing owner from a restored SceneTree pause. It passes the full seeded test without altering its assertions.
