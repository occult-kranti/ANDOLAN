# Frontage package coverage

The package guard now requires the frontage script, either directly or through its exact compiled-script remap, and the direct `assets/world/block2-frontage.json` payload. Export and package assembly bind that JSON's verified bytes and SHA-256 to the runtime source snapshot. The existing recursive source inventory and runtime UID preflight already cover the new script and its generated sidecar; their scope was not expanded.

The retained [before report](before.json) shows six absent, renamed, orphaned or substituted frontage cases admitted by the previous packager. The final [structural report](structural-review-final.json) passes **126/126**, including those requirements, valid compiled-script admission, wrong-target remap rejection, same-name/same-size JSON substitution, and missing source metadata. No existing structural assertion was removed.

Independent source review found that package-only assembly previously compared the source digest while trusting a separate file-record dictionary. The package check now compares the complete live source snapshot with the exported snapshot. A new counterexample keeps the digest unchanged while forging the frontage file record and must fail before asset/package assembly. The earlier candidate is retained as [package-native-before-review.py](package-native-before-review.py). W3's separate [6/6 call-path replay](independent-review/receipt.json) reproduced the admission on that candidate, rejected it after the correction, and retained valid and changed-payload controls; its exact ten-file closure is preserved here.

The [runtime compatibility report](runtime-review-final.json) passes all **50/50** existing exporter/runtime/default/Windows checks. Its only fixture change mocks the unrelated frontage qualification beside the existing font qualification mock. Engine admission, historical provenance pins, runtime variants and timeouts are unchanged.

The [actual-source report](actual-source-final.json) passes **6/6**: all 73 runtime script UIDs remain canonical and unique, the new engine-generated `uid://dujcxub60rkud` is admitted, the exact production JSON passes source binding, and a same-sized changed JSON is rejected. The four runtime/data/UID/caller pins remain exact to [W4's production receipt](../W4-production-r1/receipt.json). W4 separately owns its native geometry/physics/input checks; this packet does not repeat or aggregate their scope.

[Commands](commands.json), [exact executed source](executed/), [patch](source.patch), earlier reports and synthetic PCK containers are retained. No import, export, actual new package, raster review or public release was performed.
