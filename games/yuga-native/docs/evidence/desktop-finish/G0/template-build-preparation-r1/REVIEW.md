# Unmodified template-debug build preparation

**The unmodified public Godot 4.6.3 template-debug build has started; compilation and cold startup are not yet qualified.** All 13,847 original source files match the retained archive inventory. The installed editor executable remains unchanged.

The source archive is pinned to public commit `35e80b3a8822a9df9be390814b62f44c0a9c69e8`, SHA256 `fe5b661d0e7b062201ebffc8740cb309ff96c4f1edca79cdb0ecda50ff2af8d5`, 66,095,747 bytes. It now persists under `/workspace/tooling/godot-public-4.6.3/downloads/`; source objects remain in one temporary build tree. The initial safety check incorrectly rejected the archive's exact top-level directory without a trailing slash. That pre-extraction rejection is retained; the corrected check admits only that directory and safe descendants and still rejects links. No source modification or build occurred during the rejected check.

The clean dry configuration contains **2,434 compilation actions**, compared with 2,877 in the prior editor plan. X11, Wayland, Vulkan, GLES3, glTF, GDScript, advanced text and 3D rendering remain enabled. The build uses `target=template_debug dev_build=no debug_symbols=no lto=none use_sowrap=yes disable_path_overrides=no`. Public `main.cpp` parses and loads `--script` outside editor-only compilation; SConstruct retains debug runtime features for template-debug and explicitly enables path overrides. Actual raw-project script admission remains a post-build test.

The coordinator authorized four compiler jobs on CPUs 0–3 after the rendered attempt and headless fixtures ended. Exact command is in `monitor_build.py`: isolated SCons 4.9.1, `-j4`, with the options above and local Wayland scanner. The monitor reads the full `/proc/PID/stat` PPID graph, pins the root PID/starttime, and de-duplicates descendants. It records five-second sampled process RSS sums and whole-container cgroup memory separately; neither is an exact exclusive physical-memory peak. It stops its own process group below 3 GiB scratch free, at 24 GiB whole-container memory, or after two hours. Build stdout/progress/monitor logs persist under `/workspace/tooling/godot-public-4.6.3/template-baseline-r1`.

A successful binary will be hash-verified, checked against every original source file, and retained separately before any scheduling patch. The cold fixture is the exact recovered W2 eight-screen child, manifest `a02bc44bcb09cd9b80c0afd4d5a18d42a72664e23aa4961875cb572bfb39e2b5`, with fresh Godot and Mesa directories on both comparison branches. A baseline stall requires an actual native stack before the watchdog. The installed editor's source identity is different and its public-source reconstruction is unavailable; target and source differences therefore limit cross-engine attribution. Only an unmodified versus narrowly patched build of this same public template target can test the proposed scheduling change. No custom engine is shipped or promoted here.
