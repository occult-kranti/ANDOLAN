# Continuous real-receiver action capture

The silent MP4 encodes all 363 original frames from five separate actual Confluence ability takes. Deliberate fixture resets separate takes. The script enters the real world cast API; live staged receivers supply damage/heal/movement receipts. This is not human OS input, an uninterrupted fight, audio audition, online testing or a physical-GPU performance measurement.

The full report retains per-frame source/event/authority/HUD/physics receipts. Each 30 Hz capture step advanced two actual 60 Hz physics ticks; the runner validated normal expiry and current HUD/field presentation. Twenty-five original stills include gameplay samples, separate low-angle replays, reduced effects and separate hit/defeat/respawn. These stills do not alone qualify full continuous motion or adversarial locomotion.

All 363 raw sequence PNGs remain **local-only** in the scratch directory recorded in `local-raw-sequence.json`, with full hashes. This Git archive contains the compact MP4 and 25 original still PNGs, not the entire raw sequence. `contact-review-index.json` identifies actual event-adjacent raw frames for independent inspection; generated indices are not a claim of completed visual review.

Exact runtime text/metadata is preserved in `source/`; binary asset and imported-resource identities remain in the original report. Restore only with matching binaries and a fresh import cache. Independent art/effect review remains separately scoped to the actual frames it inspects.
