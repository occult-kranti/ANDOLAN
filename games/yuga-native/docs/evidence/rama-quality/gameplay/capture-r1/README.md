# Actual native five-action capture

The runner completed 363 sequential 1280×720 framebuffer samples and 25 separate
stills against actual current kit/receivers. All five takes reach natural expiry.
The complete engine log has no warnings/errors; captured runtime/import pins
remain unchanged. Encoded video was counted and decoded successfully.

The retained MP4 concatenates five independent takes in kit order, with deliberate
scene-reset cuts. Low-angle replays, reduced Guardian effects, and hit/defeat/respawn
stills are additional observations outside the video. Capture-source scripts,
raw reports, all 25 stills and original logs are retained unchanged here.

The raw report contains per-frame PNG hashes and authority/HUD truth. Raw 363
PNGs remain in the cloud scratch take and are not duplicated in Git; QA's selected
adjacent-frame evidence is separately retained. The movie is lossy encoded video,
not a reconstruction of those exact PNG bytes.

This is silent simulated30fps on software Vulkan, driven through actual world
cast entry calls. It does not prove human OS input, listening, consumer frame
rate, one uninterrupted match, continuous locomotion/traversal, native multiplayer
or completed commercial-quality art. Independent review owns the visual result.
