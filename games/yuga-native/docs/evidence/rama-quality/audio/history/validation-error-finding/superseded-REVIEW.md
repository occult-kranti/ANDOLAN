# Rama quality audio component review

Owner: role 13, original action/counter audio. Baseline inspected: `1ab1f5e330d256a6ffb6a5706a07f2ff8c3bbb0e` on `game/yuga-native-production`. Final component fixture: **91/91 PASS**, clean Godot 4.6.3 / Dummy exit with no warnings. This is an unpromoted component packet; the integration owner stages the WAVs, replaces prior Rama playback and verifies actual game lifecycle/screens before runtime acceptance.

The fifteen cues are original deterministic oscillator/resonator/filtered-noise synthesis, with no external samples, commercial audio, recordings or transcribed melodies. [Editable source and integration contract](../../../../art/audio/rama-quality/README.md) describe the cue language and API. This packet changes no legacy invocation/traversal/siege audio and does not claim a whole-game mix bound.

PCM generation, byte-for-byte regeneration and full FFmpeg decoding pass for all fifteen files: 527,700 WAV bytes; mono 48 kHz PCM16; 0.10–0.95 seconds; zero endpoints; unique hashes; finite nonzero signal; source peaks below 0.16 and absolute DC below 0.005. Generator and manifest hashes are pinned by the evidence summary. The four-player module's sample-domain estimate at gain −18 dB and slider 1 is 0.08057123 maximum summed amplitude, or 21.876 dB headroom. This calculation assumes no amplified buses/effects and enforced positional gain; resampling, actual device output and other simultaneous subsystems require separate measurement.

The runtime component owns three positional action/contact voices and one local confirmation/incoming-damage voice. Low-priority draw/contact cannot evict higher-priority releases; confirmation cannot evict incoming damage. A quiet contact on cover carries no success confirmation. Guardian healing ticks remain silent. The two later Volley pulses use the original kit's release age and existing projectile-delay ticks; there is no second audio clock, timer or delayed replay queue.

Mute, pause, focus loss, defeat, reset and teardown stop voices. Suppressed onsets are consumed. Generation/sequence/cast/timing guards prevent duplicate/reordered/re-timed events; vitals generation is bound separately from kit generation. Active casts, contact deduplication and damage-source watermarks have fixed caps. The suite tests the actual Godot Dummy-driver players and accepts unmodified live `RamaAbilityKit` / `RamaVitals` snapshots rather than translating them into invented events.

A test-only bus, real 3D listener and `AudioEffectCapture` measured one fixed maximum-slider fixture with three positional releases plus one local incoming-damage voice. It captured **28,672 stereo frames at 44.1 kHz**, peak **0.01594301** (35.949 dB observed headroom) and RMS 0.00173329. This proves numerical behavior of that one Dummy mix; it is not a bound over every phase combination, the whole game or a physical device. The temporary bus/effect/listener exist only in the test and are removed before teardown.

All five actual `RamaAbilityKit` lifecycles pass without event translation. Their observed onset counts are 2 each for primary/pierce/step/Guardian and 4 for Volley (one draw, three authority-timed pulses). Actual `RamaVitals` damage, lethal damage and generation reset receipts pass. The fixture additionally exercises 1,000 casts, four-voice prioritization, finite caps, malformed/replayed/retimed events, muted/paused/focused transitions, old/future vitals generations and actual playback retirement.

The expanded fixture initially rejected a float property at the requested pitch boundary because Godot stores that property at floating precision. The final assertion allows **1e-6** numerical tolerance while preserving the intended 0.988–1.012 range; `history/float-bound-finding.*` and its exact source are retained. A subsequent passing assertion run still warned on exit because a just-stopped Dummy playback was retiring asynchronously. The final suite tracks its actual weak reference and observes retirement within one second (**82 ms** in this run), then checks teardown. `history/async-retirement-finding.*` retains that warning and exact source. Neither historical candidate is the accepted final component report.

The first parser-only attempt failed because an inferred `WeakRef` Variant warning is an error in this project; it is retained in `history/parser-attempt1.txt`. Its corrected initial 72-case run is retained as historical supporting evidence. `component-final.json` and `summary.json` pin the final module, 91-case suite and source PCM manifest for integration.

**Listening is UNRUN.** Dummy playback, PCM statistics and numeric headroom do not establish instrument/raga authenticity, psychological effects, device behavior, dense-fight intelligibility, accessibility comprehension or commercial sound quality. The deliberately conservative gain needs in-game human mix review. Q09 remains open for those requirements.
