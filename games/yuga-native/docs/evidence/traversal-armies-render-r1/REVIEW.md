# First traversal preview review

This completed preview contains 24 consecutive actual rendered frames, 48 measured physics ticks and three staged review stills at 960 × 540. Only selected PNGs are retained here; the full source-hashed capture report lists all frames. It is not the full six-second capture.

Root and an independent UI reviewer inspected the opening HUD, active tether, overview and landing courts. Tether visibility, three long routes and raised decks were visible. The minimap legend lacked a dark backing; the permanent control list covered Rama’s lower body. Soldiers had oversized shoulder balls, solid foot markers and boxy silhouettes. Deck walls lacked surface detail. These findings caused a bounded second pass on HUD, original unit meshes and deck materials. This preview is historical evidence, not final visual acceptance.

Captured source matches commit `f5a0ef702963dad33cd0b798c9caac56883f9935` for the selected mutable sources copied alongside this review. Later changes must have separate renders and source hashes. Software Vulkan/llvmpipe was used; no gaming-GPU frame rate or commercial visual parity is established.
