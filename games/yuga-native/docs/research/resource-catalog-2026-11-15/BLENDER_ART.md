## Corrections to the supplied catalog

- **The tool's license does not clear its bundled art.** Blender allows commercial use of original artwork. MPFB expressly distinguishes GPL code from CC0 core assets. RetopoFlow's own license instead reserves rights in non-code assets. Downloaded brushes, photographs, rigs and example scenes retain their own conditions. Generated scripts can contain licensed program code even when exported geometry does not. [Blender license](https://www.blender.org/about/license/), [MPFB license](https://github.com/makehumancommunity/mpfb2/blob/9de0707fdc88438d7c53a1a2ac7937d9221e2431/LICENSE.md), [RetopoFlow license](https://github.com/CGCookie/retopoflow/blob/ac2570c5292c1dd90190fd3641b4dbc42cf4bd63/RetopoFlow.LICENSE).
- **“Blender Human Base Meshes” must identify the bundle.** The official Human Base Meshes v1.4.1 asset bundle is labeled CC0; a separate realistic-human training download is labeled CC-BY. Do not substitute one license for the other. [Official bundle listing](https://www.blender.org/download/demo-files/), [training mesh](https://studio.blender.org/training/realistic-human-research/use-of-base-meshes/).
- **Quaternius currently uses QAL v1.0 on its license page.** It permits commercial products but restricts standalone redistribution of assets, including modified copies. A raw public Git repository needs a separate distribution decision. Existing downloads with retained earlier CC0 grants must be evaluated against those original grants; this finding does not retroactively change them. [Current terms](https://quaternius.com/license.html).
- **The catalog's unsuccessful search for a geometry-nodes level kit, Niagara repository or stylized-foliage repository should not rule out procedural environment authoring.** Additional candidates include Blender Geometry Nodes, Archimesh, A.N.T.Landscape and Sapling. These provide authoring capability; they do not establish that the catalog's narrower search claim was false, supply a finished Indian temple map or prove cultural/architectural accuracy. [Archimesh](https://extensions.blender.org/add-ons/archimesh/), [A.N.T.](https://extensions.blender.org/add-ons/antlandscape/), [Sapling](https://extensions.blender.org/add-ons/sapling-tree-gen/).
- **Latest is not automatically compatible.** The handbook records Blender 4.3.2. Sapling 1.0.0 lists Blender 5.2+, while Arch Generator 1.0.1 lists 5.0+. Both require a separate version lane or an earlier qualified release; neither should trigger an unreviewed project-wide upgrade. [Sapling release](https://extensions.blender.org/add-ons/sapling-tree-gen/), [Arch Generator](https://extensions.blender.org/add-ons/arch-generator/).
- **The two temple entries are not equally cleared.** rSquare's exact model is identified, but the primary license label was inaccessible here. SrushtiLabs' Fab description states CC0 while its structured license field is blank; it also identifies the pack as AI-generated. Retain these as candidates until the actual archive and governing grant are captured. A screenshot is evidence of a statement, not a substitute for resolving contradictory terms. [rSquare model](https://sketchfab.com/3d-models/south-indian-temple-modular-kit-25f0176668004faa98ec351e04e58920), [SrushtiLabs listing](https://www.fab.com/listings/a3910c1c-1733-4851-8057-f6b433e1804b).

## A bounded Sangam art pilot

The next world-art owner should use an existing representative approach/site, not rebuild the whole map around a marketplace pack. Freeze its collision, navigation, sight-line and spawn-blocker contract first. Create a small original kit: pillar/base/capital, wall and corner, lintel, plinth/step, coping, one parapet, two rubble pieces and one vessel or lamp. Share meshes and a limited material set between variants.

Use Blender parameters for structural proportions and repeat spacing. Use one or two CC0 material sets as source inputs to the existing style. A museum image can inform the vessel or relief design if its exact media rights and context are retained. The two temple packs remain optional until their grants are resolved. Distinctive tactical cover and plant-site silhouettes must remain original layout decisions; a reusable art module does not determine competitive map design.

Deliver the editable `.blend`, export recipe, external texture sources, low/high meshes where relevant, GLB, collision proxy and a provenance record. Preserve the existing runtime/source directories and add notices/manifests with any actual asset change. Keep downloads and temporary renders in fresh scratch output; do not add whole third-party repositories or unrelated packs to Git.

The initial comparison is: current kit versus one candidate bay under the same camera, light and player route. Review front/profile/oblique views and actual traversal, then reject if the candidate harms target contrast, produces visible normal seams, hides enemies, mismatches collision, increases scene cost without useful detail, or takes longer to maintain than the current source.

## Blender → Godot contract

Godot recommends glTF and can import `.blend` by invoking Blender's glTF exporter. Explicit GLB exports remain appropriate for this project's repeatable build and existing separation of authoring assets. OBJ is insufficient for a rigged hero. [Godot import formats](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html).

Bake Blender materials to supported PBR inputs or author a deliberate Godot shader. The glTF material system is not Blender's full node system; normal maps use tangent space, and non-color maps need correct color-space treatment. Match channel packing and inspect the actual export. Blender procedural noise, geometry nodes, particle systems and rig controls are authoring data, not automatically portable runtime systems. [Blender 4.3 glTF material documentation](https://docs.blender.org/manual/sl/4.3/addons/import_export/scene_gltf2.html).

For Rama, preserve bind transforms and required deformation bones, bake evaluated clips and preserve current firearm and Q/E/C/X timing contracts. Include ready/aim, reload, cast transitions, foot support, both hands on the firearm, interruption and pause. If shape keys are present, follow the documented deformation-bone export constraint and inspect shading. A file opening correctly does not establish contact, motion or performance. [Godot export cautions](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html).

Keep repeated kit pieces as shared resources where practical. Realize instances only when the chosen export path requires it, and measure the resulting geometry. Preserve version-specific settings because later Blender node and exporter behavior can change. [Blender instance behavior](https://docs.blender.org/manual/en/4.3/modeling/geometry_nodes/instances/index.html), [Realize Instances documentation](https://docs.blender.org/manual/en/4.5/modeling/geometry_nodes/instances/realize_instances.html).

## Intake receipt and promotion gates

For each selected item, record source URL, title/author, retrieval date, exact archive/version or commit, original file SHA-256, governing license file and its hash, permitted raw distribution, attribution, modifications, export command/settings, exported hash and target runtime path. Include source textures/brushes and embedded third-party dependencies. A screenshot/HTML receipt supports license provenance; it does not overrule the grant.

Promotion requires: license and provenance checked → editable candidate made → reproducible export → structural/import checks → actual native appearance and ordinary input → required collision/animation adverse cases → measured scene cost → source/notices/manifest review. Physical GPU performance and human art/feel acceptance remain their own evidence, not inferred from software rendering or a passing headless suite.
