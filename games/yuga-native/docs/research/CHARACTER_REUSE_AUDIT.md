# Character reuse: source code, models and animation

**We can reuse selected open character assets and study reconstructed character systems now.** The best immediate native study asset is the official Godot TPS player's GLB, covered by an explicit CC-BY 3.0 asset grant. The native-engine agent is importing it into an isolated reference project. OpenLara, OpenMW and DevilutionX are useful sources for animation architecture, but their engine licenses do not supply a reuse grant for the original Tomb Raider, Morrowind or Diablo character artwork.

This bounded review inspected three reconstruction/engine projects and two open-asset games, then independently checked the chosen Godot asset. [character-reuse-sources.json](character-reuse-sources.json) records exact revisions, inspected files, hashes, model sizes and four review rounds. No commercial game binary, original commercial character model or commercial animation was extracted. The open-game IQM candidates were inspected through source/configuration and repository trees; their binaries were not downloaded by this research team.

## What we learned from the actual character code

- **OpenLara:** `setState()` accepts transitions only inside listed frame ranges; `getJoints()` builds a hierarchy and can override selected joint rotations. `readModels()`/`readAnims()` map explicit binary fields into model/animation records. YUGA can use its own action windows and upper-body layer, with authoritative movement and ability timing kept separate from interpolated presentation.
- **OpenMW:** `setObjectRoot(..., baseonly=true)` creates the skeleton foundation for separately attached body parts. `addAnimSource()` replaces `.nif` with `.kf`; later sources have priority. `play()` combines animation priority, bone masks and named start/stop/loop markers. YUGA's costume and weapons should use stable sockets and explicit action priority instead of hard-coded per-frame offsets.
- **DevilutionX:** the CLX loader separates missing/failed reads from an owned sprite buffer. The animation code spreads skipped visual frames before the action point while explicitly leaving game ticks unchanged. YUGA should preserve accepted release/contact timing when speeding, blending or interrupting an animation.
- **Red Eclipse:** the IQM loader reads position/normal/UV plus four byte-sized bone indices/weights, constructs parent-linked inverse bind transforms and decodes masked frame channels. Its coordinate adjustments demonstrate why an imported skeleton needs axis/rest-pose validation before retargeting.
- **DarkPlaces/Xonotic:** the IQM loader validates signature/version, reads joint/pose offsets and four-component skin weights, then builds named animation scenes with frame range/rate/loop metadata. Retargeting should retain those clip boundaries; a list of names alone does not prove the poses or timing survived conversion.

These are source-supported engineering observations, not recovered Deadlock/Overwatch models or hidden commercial behavior.

## Exact model to use now

Use **`godotengine/tps-demo/player/model/player.glb` at `a82f15448e9b015440d3bbdf5e10801b260c4e9f`**, in the isolated reference project owned by the native-engine agent.

- SHA-256: `16b783ec2e19245d034326d401796b9bd2635de75f4e38917854316abeee4f9c`.
- Git blob SHA-1: `d4cfd9ac472f1a9798f6daa1ad0e78b6c75a5575`, independently matched to the pinned repository tree.
- The **GLB alone is under 25 MB**. Its four texture maps and two source materials add about 6.65 MB; the complete textured source bundle exceeds 25 MB. It must not be described as a fully textured sub-25-MB package.
- The 56 entries include numerous `-noexp`/test/helper names. They are an inventory, **not 56 verified production clips**. Start with `Idle-cycle`, `running_nogun-cycle`, selected `strafe_*` and `jump_*` tracks, checking actual imported names and motion.
- Retain the original skeleton first. For transfer to YUGA, create an explicit human-bone map, compare rest pose/axes/scale, transfer one locomotion clip, bake it, then verify feet, hand/weapon contact, joint limits and root movement. The robot's cannon-specific actions are not automatically appropriate for Rama's bow.
- Keep attribution, exact license copy, source revision and modification/conversion notes beside the study asset. The current audit does not approve replacing or rebranding a YUGA hero with it.

The direct GLB inventory check is complete. Godot import, clip playback and rendered visual acceptance belong to the native-engine agent's separate evidence. A successful structural parse is not an animation-quality pass. The full upstream TPS project currently declares Godot 4.7; selected source patterns and the model are being evaluated in YUGA's installed 4.6.3 environment, rather than assuming whole-project compatibility.

Do not expand downloads until these steps answer whether reuse actually improves YUGA's motion.
