## Provenance and scope

The inventory compared 1,206 eligible paths across six historical scratch groups and the generated-image directory against Git objects reachable from local refs and native production commit `82b1a4d3`. It compared exact payload bytes. The selected 29 files total 30,449,993 bytes. All four generated originals already matched versioned blobs.

The project-specific previews and Blender study inherit the Hanuman and Rama source attributions. Consult the exact input manifests for reused topology and maps. The saved study, its stage hashes, and the maintained builder give editors a reproducible starting point for new work. Historical stage scripts can differ from the current implementation.
