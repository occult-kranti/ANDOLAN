# Hanuman’s five abilities

Download the native offline practice build, extract it, and run the launcher. Choose **Hanuman → Begin Hanuman Trial → Begin practice**. The extracted Linux launcher completed all five abilities, returned to the title and quit cleanly on both Forward+ and Compatibility under software rendering. The Windows executable and its bundled game data passed archive inspection. The Godot trial plays the revised motions on the original 167-joint rig and uses the same combat rules as the independent tests. The editable temple scene shows how the animations look with the detailed studio surfaces. ## Inspect, edit and reproduce

- **Watch the trial.** The 17-second native gameplay reel shows the five practice actions at 1280 × 720. The shot list, per-frame events and sound edit can be reproduced. The sound edit uses the game’s cue files at the measured event frames.
