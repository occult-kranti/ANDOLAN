# YUGA — longer lanes, flight and army practice

The native Confluence arena is now 140 × 260 m with longer three-lane routes, eight landable decks, ten tether anchors and animated spear soldiers, bow guards and banner commanders. Paired waves fight, threaten cores and award once-only player last-hit gold. Reset starts a new local practice round.

Extract the entire Linux or Windows ZIP. Run `launch.sh` or `launch.bat`, then choose **Explore Confluence**. Linux execution is reviewed separately from Windows archive validation. The default Forward+ renderer requires Vulkan; `--rendering-method gl_compatibility` is a reduced-effects fallback.

Default controls: WASD move, mouse aim, left click bow, Space jump/rise, Ctrl descend, Shift sprint, Q pulse, E dash, R reload, F toggle flight, G tether/release, F1 overview, F2 help/remap, N daylight, Escape pause, F5 reset. Settings retain sound, sensitivity and custom bindings. Flight and tether need energy and a clear target.

The original music loop is included separately as `lane-procession-loop.wav`. Its synthesis, cue provenance and numerical tests are documented; human listening review is not claimed. `TRAVERSAL-VERIFICATION.md` identifies current evidence and practical limits.

This is offline native practice. Competitive native multiplayer, the full hero roster and production-quality character art remain open. The generated army/map concept is a future visual target. The separately included 24-second Confluence duel movie is unchanged archived cinematic work; it does not depict these new traversal mechanics.
