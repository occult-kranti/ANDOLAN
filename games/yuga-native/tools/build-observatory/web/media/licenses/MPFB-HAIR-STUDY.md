# Reused Rama hair authoring study

`rama-mpfb-profile.png` and `rama-mpfb-rear.png` are actual Blender 4.3.2 Cycles CPU renders of the existing Rama model with an isolated fitted rear hair study. The donor guide curves are by Tomáš Klecer, from the official MakeHuman/MPFB Hair editor functional asset pack, whose assets are CC0. MPFB tool code is GPL-3.0-or-later; tool and asset licenses are distinct. This work uses the asset datablock directly and does not claim the current add-on menu was installed or compatible.

Original project body, crown and rig retain existing repository provenance. Donor source SHA256: 93aedaef061dc14618a0fcfad33c3df816fa755e8093381cbdfd0fd4c34527f5. The source packet retains the official catalog grant, author attribution, exact donor, editable master, scripts and actual renders.

These images accept an editable direction only. Hair-card/texture baking, skin binding, LODs, animated contact and native rendering remain unqualified. The canonical game hero has not been replaced. This is not finished Deadlock-quality art.
