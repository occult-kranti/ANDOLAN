# Bundled Noto fonts

Unmodified Noto Sans Regular and Noto Serif Regular provide consistent game typography across installed systems. The font binaries are licensed under SIL OFL1.1. COPYRIGHT.txt preserves the distribution notice and full license; its Debian packaging section describes package metadata rather than these font binaries. Exact local package version and SHA-256 identities are in manifest.json.

Tactical symbols use the separately attributed DejaVu Sans fallback. The rejected Noto Symbols fallback caused excessive line spacing; its original frozen UI evidence is retained outside the active asset set.
