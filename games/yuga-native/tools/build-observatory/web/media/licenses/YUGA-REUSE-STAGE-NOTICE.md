# YUGA reuse-stage previews — 23 October 2026

The wind-court images are actual software-rendered views of the existing
original YUGA world and one original architectural pilot, using the project's
existing materials, geometry utilities, hero, troops and map. They are not
commercial-game screenshots or a historical reconstruction.

The effects witness reuses the original generated diya described in
`CLOUD-DIYA-PILOT.md` and the existing YUGA event-driven ability presentation.
The rendered flame replacement and study composition belong to this project.
It is an isolated staged presentation study, without gameplay authority or a
new hero animation. Its exact source, actual frames, held automated checks and
independent visual review are retained in the repository under
`games/yuga-native/art/ten-rounds-oct23/vfx/`.

Godot (MIT) and Blender (GPL software; output provenance separate) are reused
tools. Their source/build/runtime notices remain in the repository and native
release. The browser viewer continues to ship its PlayCanvas MIT notice and
the local Noto font notices. Existing source/model/material notices remain
beside this file. The desktop quality target is not yet achieved.
