# Existing Lanka gate → one playable lane section

Uses the original CC0 `assets/environment/lanka_courtyard.glb` with the checked native loader already in `tools/map-reuse-intake/`. No downloads, new architecture generation or commercial game art. Full source/limits and ten conditional stages are in `docs/research/reuse-next-ten/W4/README.md`.

- `prepare.py`: independent raw GLB/accessor/whole-connected-piece selection; fresh scratch fixture, read-only source symlink and source receipts. Emits 241 pieces/17,862 triangles/11 surfaces.
- `placement.gd`: preserved source vertex/normal/tangent/UV/material extraction, rigid native-metre placement, one source-triangle collider.
- `test_placement.gd`:22 native isolated checks; actual 0.65 m×1.8 m clearance, camera/LOS/cover and injected broad-blocker controls.
- `capture.gd`, `capture_ordinary.gd`, `capture.py`: actual full-world Forward+ source-bound comparison, real scripted CharacterBody route, then correctly evaluated ordinary idle views. Root grants one renderer lane;2 software threads, owned display, bounded timeout, real image hashes and engine-error checks. The original held A-pose stills remain diagnostic; correction never relabels a different view as their baseline.
- `bake.gd`: selected original resources → self-contained compressed standard native PackedScene. It also preserves original collision faces, avoiding render-mesh re-decompression drift.
- `probe_bake.gd`: all source array/native material/image-byte correspondence; resource sharing, per-instance collision ownership, malformed cached-scene negatives, duplicate prevention and teardown. `--reference-only` checks a fresh rebuild without changing the qualified artifact's strict runtime hash.
- `runtime_gate.gd`: isolated prototype copied to the leased production helper after approval; no source GLTF parse per gameplay load. One cached native scene, shared immutable mesh/material resources, uniquely owned physics body/shape, fail-closed asset/source geometry budgets.
- `test_integrated.gd`: actual default canonical caller plus explicit legacy opt-out, preserved 8 authority/8 deck/10 anchor identities, full-map lane/rotation sweeps, both actual and margin army traces, real camera sphere and old-broad-box negatives.
- `probe_package.gd`: **external**13 check proof against a real exported PCK. Launch the qualified runtime with `--main-pack /absolute/exported.pck --script /absolute/path/probe_package.gd -- --expected-pack=/absolute/exported.pck --output=/fresh/report.json`. It requires mounted `res://project.binary` (absent in source), checks actual packaged FileAccess+SHA, loads the production helper, verifies shared resources/unique collisions and real opening/cover physics. The expected-pack argument labels report identity; the launcher separately records actual `--main-pack` argv/hash from outside checkout. Source tests do not substitute for it.

To rebuild the candidate asset, invoke `bake.gd -- --selection=/fresh/selection.json --output=/fresh/lanka-lane-gate.scn`; retain that exact approved artifact hash. Godot internal resource IDs may differ on clean rebuild, while all source attributes/material bytes/collision must remain equal. A runtime artifact hash update requires that review; never silently accept an arbitrary scene.
