# Source-preserving hero cleanup tools

See [the bounded experiment and rejection](../../art/ten-rounds-oct23/cleanup/README.md) for executed commands, hashes, actual images and limits. The original and runtime are immutable inputs.

- `audit_source.py`: source import, exact-coordinate connectivity retaining every face, and separately labelled Blender weld diagnostic.
- `cleanup_candidate.py`: reproducible local dark-hair experiment; original-byte GLB patch to POSITION/NORMAL only. The produced candidate failed artistic review.
- `verify_patch.py`: independent stdlib byte/mask/delta eligibility check.
- `test_verify_patch.py`: nine real-candidate positive/corruption checks; no file mutation.
- `render_comparison.py`: five matched CPU frames from the pinned packed studio; requires root's heavy render lane.
- `freeze_studio_contract.py`: data-only frozen camera/lights/material/source geometry contract.
- `inspect_donor.py`: data-only audit of the separately licensed pre-C1 donor object; no replacement or render.

The candidate is not a production repair. Do not rerun parameter loops or generate LODs from a structurally valid but visually rejected asset.
