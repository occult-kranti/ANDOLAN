# Reuse and notices

The offline window report imports this repository's already-retained Python adaptation of `ValveResourceFormat/ValveResourceFormat` `SampledAnimationEvents.cs`, commit `a2d07483864d380940f61abf52ddfcb905a00633` (MIT, Copyright © 2015 ValveResourceFormat Contributors).

The [complete MIT text](../../docs/research/reuse-next-ten/reuse-advisor-world/sources/ValveResourceFormat--ValveResourceFormat/LICENSE.txt), [upstream source hashes and modification notice](../../docs/research/reuse-next-ten/reuse-advisor-world/NOTICE.md), and actual original-game adapter remain in place. This tool imports that adapter rather than making another copy. The runner pins the adapter separately in each inspection output.

The capture subclasses, joins, admission checks and counterexamples are project additions. They reuse this repository's existing original Rama runtime, rig, animation and audio assets. No Overwatch, Valorant or Deadlock game assets, binaries, leaked source, model files or maps are included. OWLib's attachment metadata motivated the earlier proposal but no OWLib parser is imported or executed here.
