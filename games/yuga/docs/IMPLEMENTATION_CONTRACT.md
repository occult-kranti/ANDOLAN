# YUGA: Confluence — shared implementation contract

New original browser arena in branch `game/yuga-confluence`. Existing ANDOLAN remains at its public root. Target publication: `/ANDOLAN/yuga/` with its own app, settings and save/session keys. The protocol-2 prototype has fourteen heroes, seven unit models, jungle and contested-gold mechanics; optional guidance, city lighting and the west coastal court are the current revision. Final acceptance is recorded in QA, not implied by this contract. No AAA or generated-key-art parity is claimed.

Root owns shared types/map contracts, client main/CSS/input/connection, Vite/package/configuration and deployment. Systems owns shared/simulation.ts, server and simulation/network tests. World owns client/world.ts and rendering helpers. Content owns shared/heroes.ts and mythology/design research. Audio owns client/audio.ts. Research owns game/open-source analysis and provenance. QA owns browser/stress verification after the integrated client is ready.

## Shared APIs

All state types live in shared/types.ts; collision/lane coordinates in shared/map.ts. Discuss changes before editing those shared contracts. `shared/heroes.ts` exports `HEROES: HeroDef[]`, `heroById(id): HeroDef`, and optional roster text. Fourteen selectable heroes, three abilities each: five Vanguards, four Strikers and five Keepers. Every kit has a distinct ordered ability composition. All heroes and slots are available at match start; unknown join IDs are rejected separately from the internal rendering fallback.

Simulation export `class ArenaSimulation` constructor `(options?: {room?:string;seed?:number;duration?:number;botsPerTeam?:number})`; methods `addPlayer(id:string,name:string,heroId:string,team?:Team):Actor`, `removePlayer(id:string):void`, `input(id:string,input:ArenaInput):boolean`, `command(id:string,command:ArenaCommand):CommandResult`, `step(dt:number):void`, `snapshot():ArenaSnapshot`. All clients share authoritative rules; browser practice uses the same simulator. Default three heroes per team including the human; fill with bots. Server owns identities, reconnect tokens and input validation. No client-authoritative hits, rewards or timers. Stable command IDs prevent duplicate purchases/ability casts.

Match: three lane minion waves, three towers each side, core opens after two friendly towers fall; destroy opposing core or use score/core-health tiebreak at eight minutes. Death/respawn, gold upgrades at spawn, neutral pickups, bot pressure on all lanes. No paid power, loot boxes, streak loss or mandatory login.

Waves start at one second and repeat every eighteen seconds, with three escorts per lane per team: soldier, city watch and minister. Every third wave, starting at 37 seconds, also includes one king siege unit per lane per team. Capacity limits admit mirrored team pairs. Summons expose role/summoner/expiry metadata; their current lifetime is nine seconds, placement respects collision, and defeating them grants neither gold nor team score. Role-specific art cannot change target priority, damage or unit lifetime. Four jungle courts and contested gold shards use the server-owned rules in [MINIONS_AND_JUNGLE.md](MINIONS_AND_JUNGLE.md).

Three R abilities use explicit authoritative cast state: Rama's one-second locked three-arrow volley, Hanuman's 0.7-second preparation plus 0.45-second collision-limited travel and landing payload, and Sita's 0.8-second preparation followed by a fixed six-second sanctuary. Inputs cannot move, fire, jump or recast through preparation/travel. Death cancels an unfinished cast without refund; an already-created sanctuary lasts its duration after owner death. The other thirty-nine slots keep shared-kind behavior. Content descriptions, cast HUD, animation and effects must agree with the source values and snapshot timing.

Renderer export `createArenaWorld(canvas:HTMLCanvasElement):Promise<ArenaWorld>` with `update(snapshot,playerId,dt)`, camera/quality/reduced-motion/active controls, `setLightingMode('cycle'|'day'|'night')`, projection/reticle helpers, hero/unit preloading, asset diagnostics and `destroy()`. `client/world.ts` defines the current complete interface. Camera looks along yaw (`sin(yaw), cos(yaw)`) with positive pitch looking up; third-person behind avatar. Map visuals respect shared solids and lane clearance. Root handles screen-space HUD/minimap/input. Cosmetic lighting follows the 480-second snapshot clock, with saved fixed modes; it cannot change collision, targeting, damage or visibility eligibility.

`HeroModelLibrary` loads the actual external GLB containers, shares immutable geometry/material/animation resources, and creates independent skinned instances. The asset route uses pinned MakeHuman CC0 base anatomy, rig and weights with original costume, hair, weapons, materials and motion. Required exported clips are `idle`, `run`, `fire`, `cast`, `cast1`, `cast2`, `cast3`, `jump`, `defeat`; root motion stays disabled so authority owns translation. A fallback can preserve availability but cannot pass the model-art gate. Concept images are never treated as runtime avatars. Final model/pose/clip acceptance requires the manifest verifier and actual-engine captures.

Audio export `ArenaAudio`: `unlock():Promise<void>`, `setVolume(number)`, `setMuted(boolean)`, `setActive(boolean)`, `update(snapshot,playerId)`, `preview():Promise<void>`, `destroy():void`. Gesture-started original synthesized cues, spatial cues where useful, bounded voices/cleanup, silence when menu/hidden.

Native input: WASD/arrows camera-relative motion; mouse/drag or IJKL aim; click/F fire; Q/E/R abilities; Space jump; B upgrades; Escape pause/settings. Dash is a hero ability, not an undocumented universal Shift action. Touch provides movement/aim and action buttons. Menus release held input and restore focus. Online menus pause only the player's input, never shared simulation. Development read-only diagnostics support QA; no production debug hook.

Loading keeps local Practice paused and the HUD inert until the local actor exists and two actual engine `postrender` events have occurred. Back/Escape cancels that wait; stale completion must not start a late session. Online server time continues while the client loads. The decorative West Reed Court wet surface is flat walkable ground and adds no swimming, slowdown, damage or collision rule.

Optional target lock is client aim assistance, toggled with T/right-click/touch LOCK and disabled through Settings. Acquisition requires an eligible visible enemy within 32 metres and within 20 degrees of current aim. Eligible targets include living enemy heroes/minions, active neutral guardians and unshielded enemy structures. Visibility/range/alive status is revalidated while locked; manual mouse/drag/IJKL aiming releases it. The acquisition cone does not limit retention. Locked casts retain their accepted facing/target instead of following a later lock movement. There is no automatic fire, homing projectile or client-authorised hit. Final native keyboard/mouse/touch and cover-break evidence is a separate integration gate.

`shared/hero-guide.ts` provides a typed guide for each of fourteen IDs: first action, position, three ordered skill notes, counterplay, actual upgrade tradeoffs and an optional prose exercise. Unknown guide IDs return `undefined`. `client/practice-goals.ts` observes one of five optional goals from actual snapshots/receipts without sending commands or granting rewards. Free play is the default. Pause preserves progress; dismissal removes it; replay starts a fresh session baseline. These goals are Practice-only and never certify mastery. The current source review and separate native gates are in [NEXT_PHASE_PANEL.md](NEXT_PHASE_PANEL.md).

## Build and publication contract

Vite emits the client plus separately cached, hashed GLB assets. Serve/copy all of `dist/yuga/`; an isolated downloadable HTML file is no longer a complete game build. The combined Pages assembly recursively preserves this directory under `dist/site/yuga/` and keeps ANDOLAN at the root. Static hosting provides Practice. Online play additionally requires the supplied Node/WebSocket service to be deployed and verified; a Pages deployment does not run it. Reconnect identity is currently process-memory state, not an account or persistence guarantee across server restart.

`npm run yuga:package` builds and verifies all 21 manifest-listed GLBs before packaging the entire static directory as `dist/yuga-confluence-browser-beta.zip`. It adds HTTP-serving instructions and source/file identity in `BUILD_INFO.json`; it does not provision a server. Client and online server must both speak protocol 2. Actual package/build/public checks remain separate release evidence.

Finite release gates: all fourteen roster kits usable; all fourteen actual GLBs/hash/skin/animation checks; three-lane bots/objectives/finished match/replay; normal-input combat/ability/upgrade/settings/target-lock tests; two real WebSocket clients and reconnect; malicious command rejection; bounded simulation/socket stress with actual machine/scope numbers; asset provenance; full static-bundle publication and live URL verification; runnable server deployment files. The 168-match AI comparison is bounded bot evidence, not human competitive balance. Broader cultural review, finished character polish and operated public multiplayer remain explicit gates.
