# Reference-game study → original mechanics lab → YUGA

Opened 16 October 2026. The user's new direction is to study Deadlock and Overwatch systems through REA and available open-source projects, build reviewable reference experiments, then use the findings to improve YUGA. **The first executable deliverable is an original mechanics lab using YUGA's existing simulation, city and models.** It is not an independently playable copy of either commercial game. This roadmap is a new workstream. The earlier [guidance/coastal review](NEXT_PHASE_PANEL.md) closed with its own public acceptance; that evidence does not certify the new lab.

The existing reference studies contain useful source code, documentation and bounded REA results. They do not contain either commercial game's complete source, authoritative server, current patch measurements or observed gameplay footage. The concrete route is: pin a source and question → inspect its implementation → record what remains unknown → implement an original, explicit rule → test that rule → compare only observations for which a lawful, versioned reference input is actually available. A broad resemblance is design context, not measured parity.

The [canonical control-point source](../reference/objective.ts) defines a centre at (0,0), radius 8 m. Six uncontested seconds capture it, with no headcount speed bonus. Eligible occupants are connected, living hero actors with no respawn delay and height at most 2 m; summons/minions do not capture. An owner scores one point per second only while that team has eligible presence and no opponent contests; the goal is 60 points. Contest freezes capture and scoring. An empty point retains ownership and awards no score; unfinished capture decays by one-sixth of its normalized bar per second. An uncontested returning owner immediately clears a hostile unfinished capture before scoring. These original rules have source, unit and bounded native acceptance recorded in the lab QA ledger; the three lab routes also pass public lifecycle smokes. Height ≤2 m is an eligibility threshold, not a grounded-only rule.

Both presets retain the underlying arena's 480-second engine limit. The hybrid adds its own reachable 240-second deadline. Finish precedence is: an already-finished underlying arena outcome (including core destruction) first; otherwise reaching 60 control points; otherwise, at the hybrid deadline, higher control score or a draw. Thus core destruction can end the hybrid before its point goal. The HUD must show this explicitly, rather than imply that control ownership overrides core loss. Lab primary fire has 12 rounds and a 1.6-second simulation-time reload on X, paused with menus. The optional trusted local `onPrimaryShot` observer receives an immutable `{actorId, projectileId, tick, time}` exactly once per successfully created hero-primary projectile. Cap rejection, ability projectiles and minion shots emit no such receipt. This direct creation signal supplies ammo accounting even when the bounded FX history evicts an event; it is not inferred from that history. Observers must be nonthrowing and nonreentrant: this is a trusted adapter contract, not an isolated extension sandbox. Q/E/R do not consume magazine ammo. Health, speed and all fourteen kits' ability cooldowns stay unchanged.

The first lab is offline, uses normal authority input for bots, records observed net wallet deltas and bounded receipts, and awards no invented objective credits. The [controller and API](../reference/controller.ts) reconcile each command/action and simulation step separately; `balance = initial + observed increases − observed decreases` is an accounting check, not proof of source-level earnings. A later source-correlated ledger must identify reward event/source/recipient and missing records explicitly. A pure control map without ordinary lanes/towers/camps is later scope. This contract does not authorize a large item catalog, new hero roster, universal mobility system, ranked service or arbitrary executable scripting. Those are later, independently scoped work below. It also does not require reading a growing bibliography before shipping the bounded lab.

## Evidence handoff required for each comparison

Each record needs a question, source URL/commit and reading boundary; any executed REA command with input/output hashes and unknowns; the original lab rule/preset revision; seed, actors, mode and actual event/timing observations; expected/observed outcome; and whether evidence is source-only, synthetic, staged, native local, real-network or public production. Attach a small counterexample or failed case whenever it changes the interpretation.

A later reference measurement must identify its lawful input, patch/build, timestamp and uncertainty. Do not retroactively call the existing GitHub reading a watched match, an executed parser, a recovered commercial engine or a completed book. Prefer a new small experiment that resolves a concrete unknown over downloading more unrelated repositories.
